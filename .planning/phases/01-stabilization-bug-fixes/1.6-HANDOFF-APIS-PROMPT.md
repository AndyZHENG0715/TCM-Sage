# Phase 1.6 Handoff: APIs, Runtime Params, Prompt/Sanitization

## Current Objective
Hand off enough implementation context so another AI agent or TCM domain expert can redesign the system prompt and answer quality contract without losing engineering constraints.

## Known Status (as of this handoff)
- Full-context citation flow is fixed for newly generated citations.
- Mobile access via forwarded domain now routes through Next.js proxy (`/api/backend/*`) and no longer depends on client-side `localhost:8000`.
- Android lock/screen-timeout interruptions remain a browser/OS limitation for long-running streaming requests.
- Remaining high-priority product issue: answer quality + occasional model tendency to append trailing source-like sections.

## Public Web <-> Backend API Contract

### 1) `POST /api/backend/query` (proxied to FastAPI `POST /query`)
- Purpose: stream answer tokens + final metadata event.
- Request JSON:
  - `question: string`
  - `chat_history: Array<{ role: string; content: string }>`
  - `settings?: {`
    - `provider: string`
    - `model: string | null`
    - `informational_temperature: number`
    - `prescriptive_temperature: number`
    - `classifier_follow_main: boolean`
    - `classifier_provider: string | null`
    - `classifier_model: string | null`
    - `verifier_follow_main: boolean`
    - `verifier_provider: string | null`
    - `verifier_model: string | null`
    - `retrieval_k: number`
    - `hybrid_retrieval_enabled: boolean`
    - `graph_depth: number`
  - `}`
- Response: SSE stream
  - text chunks: `data: <token text>`
  - final metadata event: `event: metadata`, JSON payload includes:
    - `citations`
    - `severity`
    - `verification` + `verification_result`
    - model/provider/runtime details

### 2) `GET /api/backend/config`
- Purpose: bootstrap runtime defaults for UI settings.
- Response includes provider/model/temps/retrieval/hybrid state.

### 3) `GET /api/backend/health`
- Purpose: backend reachability check.

### 4) `GET /api/backend/source/{chunk_id}/context`
- Purpose: return full chapter context and paragraph highlight offsets.
- Used by citation panel and source page.

### 5) `GET /api/backend/books/{book_name}`
- Purpose: load full source-book text for "Full Book" mode.
- Backend supports:
  - prefixed filename matching (e.g. `439-黄帝内经太素.txt`)
  - decoding fallback for mixed file encodings (`utf-8`, `utf-8-sig`, `gb18030`, `gbk`, `big5`)

## Prompt & Generation Flow (Backend)
- Main prompt build path:
  - `src/main.py` -> `build_prompt_template()`
  - Source cleanup helper: `strip_sources_directive(system_prompt)`
- Runtime execution:
  - `src/ui_backend.py` -> `run_query_stream()`
  - uses `format_docs_with_citations()` from `src/main.py`
  - severity split via classifier:
    - informational model temp
    - prescriptive model temp

## Citation ID Construction (Critical)
- `src/main.py` -> `format_docs_with_citations()` now reconstructs canonical `chunk_id` as:
  - `"{book}_chunk_{chunk_index}"` when vector document `id` is missing.
- This aligns with Chroma IDs and is required for context endpoint correctness.

## Current Sanitization Layers

### Rendering sanitization (frontend)
- `web/components/MessageBubble.tsx`
  - `postProcessAssistantContent()`
  - strips trailing source/reference sections when model appends sections like:
    - `Sources:`
    - `References:`
    - Chinese equivalents (`参考资料`, `参考文献`, `资料来源`)
  - only strips when heading is followed by list-like reference items.

### Source context normalization
- `web/lib/api.ts`
  - decodes potentially encoded `chunkId` once, then re-encodes for request URL.
